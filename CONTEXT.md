# Chat

A real-time one-to-one messaging system. Messages are delivered over a persistent socket,
moderated server-side before they become visible, and must survive disconnection without loss
or duplication.

## Language

**Conversation**:
A durable one-to-one thread between exactly two participants. Created once and reused; there is
never more than one Conversation for a given pair.
_Avoid_: Chat, room, thread, DM

**Participant**:
A User's membership in a Conversation, carrying that user's own per-conversation state such as
their read mark.
_Avoid_: Member, subscriber

**Message**:
A single unit of content sent by one Participant into a Conversation. Immutable once accepted.
_Avoid_: Post, entry

**Client Message Id**:
A UUID generated by the sending client before the Message leaves the browser. It is the
idempotency key: the same Client Message Id sent twice yields one Message, never two.
_Avoid_: Temp id, local id, nonce

**Accepted**:
The state of a Message once it is durably stored by the server. Acceptance is the boundary the
system promises never to silently lose a Message past.
_Avoid_: Saved, persisted, committed

**Refused**:
A Message the server declined to Accept, so it was never stored and can never be delivered. A
refusal names its cause — the prohibited term that tripped moderation — and reaches only the
sender; the recipient never learns the Message was attempted. Distinct from a failed send, which
is a Message the server never ruled on and which is retried.
_Avoid_: Blocked, filtered, censored

**Read Mark**:
A Participant's high-water mark — the most recent Message they have read, held as that
Message's Sequence. Everything at or before it is read; everything after is unread. Reads are
monotonic and never move backwards.
_Avoid_: Receipt, read state, seen flag

**Unread Count**:
The number of Messages in a Conversation after a Participant's Read Mark. Derived, never stored.
_Avoid_: Badge count

**Presence**:
Whether a User currently holds at least one live socket connection. Derived from live
connections, not stored as a field.
_Avoid_: Status, online flag

**Sequence**:
A Message's position in the single, strictly increasing order shared by every Conversation.
Assigned by the server when a Message is Accepted and never reused or reordered. One Sequence
underlies four readings of the same number — sort order, the page boundary a reader walks back
through, a Sync Cursor, and a Read Mark — so these are views of one value, not four quantities
that could disagree.
_Avoid_: Timestamp, index, position, offset

**Sync Cursor**:
The most recent Message a client already holds, sent on reconnection so the server can return
only what was missed. A reading of that Message's Sequence.
_Avoid_: Watermark, offset, checkpoint
